# Арена переговоров

Симулятор деловых переговоров с ИИ-оппонентом. Кейс №9 «ОЭЗ Алабуга», хакатон «Лидеры цифровой трансформации 2026».

**Демо:** https://web-production-d26833.up.railway.app

## Проблема

Навык переговоров нужен в закупках, HR и продажах, но тренироваться на живых сделках дорого и рискованно. Тренинги с живым партнёром сложно масштабировать, а разбор ошибок обычно субъективен.

## Решение

Пользователь ведёт диалог с ИИ-оппонентом, у которого своя роль, цель и линия поведения. Каждый раунд оценивается, а прогресс показывается через геймификацию.

## Возможности

- Три сценария под разные сферы:
  - закупки: снижение цены у поставщика;
  - HR: зарплатные переговоры с кандидатом;
  - инвестиции: питч стартапа инвестору.
- LLM-оппонент на Gemini API, реплики генерируются под ход диалога.
- Шкала напряжения переговоров.
- Очки за каждый раунд, XP и ранг переговорщика (прогресс хранится в localStorage).
- Офлайн-заглушка: при сбое LLM игра продолжается на заготовленных репликах.

## Целевая аудитория

Менеджеры по закупкам и продажам, HR-специалисты, предприниматели и студенты, которым нужно отработать навык переговоров без риска для реальных сделок.

## Архитектура

| Слой | Технологии |
|---|---|
| Frontend | HTML, CSS, JavaScript (без фреймворков) |
| Backend | Python, FastAPI |
| База данных | SQLite |
| LLM | Gemini API (`gemini-3.5-flash-lite`) |
| Деплой | Railway |

Браузер обращается к FastAPI, backend хранит сессии в SQLite и запрашивает реплики оппонента у LLM. Если LLM недоступна, ответ берётся из офлайн-заглушки.

## Запуск локально

```bash
git clone https://github.com/taoroa12/arena-negotiation.git
cd arena-negotiation
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

Создайте файл `.env` в корне проекта:

```
LLM_PROVIDER=gemini
GEMINI_API_KEY=ваш_ключ
```

Запуск:

```bash
uvicorn main:app --reload
```

Откройте http://127.0.0.1:8000

Без ключа приложение запустится и будет работать на офлайн-заглушке.

## Как проверить (сценарий для жюри)

1. Откройте демо-ссылку.
2. Выберите сценарий, например «Закупки».
3. Проведите 3–5 раундов диалога и следите за шкалой напряжения.
4. Посмотрите начисленные очки, XP и ранг.
